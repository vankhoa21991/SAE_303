# IMG_0946 — Page 20: Simple exponential smoothing (LES/SES)

**Content:** **4.1(§) Lissage exponentiel simple (LES ou SES)**.

- Figure 18: potato price prediction via simple smoothing (observed vs. fitted, quarterly 2009–2018).
- Model: x_t = a + e_t (no trend/seasonality, locally constant mean). Idea: find the constant forecast minimizing a weighted least-squares problem with geometric weights β^j.
- Formal definition: x̂_T(h) = (1−β)·Σ β^j·x_(T−j), where β ∈ [0,1] is the smoothing constant.
- Remarks: name comes from exponential decay of weights; when β is independent of h, all forecasts equal x̂_T(1); β near 0 → "souple" forecast (heavily weights recent data, β=0 → last observed value); β near 1 → "rigide" forecast (remembers far into the past, β=1 → forecast is constant/equal to initialization).
- Boxed **Proposition (Initialisation/mise à jour)**: initialization x̂₁(h)=x₁ (or x̄); update rule x̂_T(h) := β·x̂_(T−1)(h) + (1−β)·x_T, with handwritten labels identifying "prévision précédente" and "valeurs observées précédentes."
