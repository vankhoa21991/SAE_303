# IMG_0934 — Page 8: Buys-Ballot method

**Content:**

- Tableau 3: quarterly electricity consumption of an internet retail company, 1997–1999, with a superimposed-curves chart (Figure 5). Model determined by hand: **additif**.
- **Méthode du tableau de Buys et Ballot**: compute the mean and standard deviation for each year, then fit a linear model s_Y = a×Ȳ + b between std-dev and mean via least squares.
  - If a ≈ 0 → std-dev doesn't depend on the mean → additive model.
  - If a ≠ 0 → std-dev depends on the mean → multiplicative model.
- Two full worked examples side by side (2003–2006, quarterly data):
  - **Modèle additif** table + scatterplot of écart-type vs. moyenne, regression line "écart type = 0.0613 moyenne + 17.18," slope ≈ 0 → additive, with handwritten justification.
  - **Modèle multiplicatif** table + scatterplot, regression line "écart type = 0.1148 moyenne + 8.8078," slope clearly nonzero → multiplicative, with handwritten justification.
