# IMG_0950 — Page 24: LES worked example & limitations

**Content:**

- Worked example reusing the France aviation-fuel-sales data (Tableau 9, same as Tableau 5).
- Tableau 10: spreadsheet showing LES with α=0.4 computed column-by-column (formula =0.4*B3+0.6*C3), plotted alongside the raw series x_t in a line chart (values 1–18).
- Tableau 11: detailed LES calculations with error metrics (e_t, ABS(e_t), (e_t)²) computed for α=0.4 and α=0.5, with EM/EAM/EQM totals for each.
- Tableau 12: sensitivity table showing EM, EQM, EAM for α ranging from 0.1 to 0.9 (on the last third of the series), letting one pick the α that minimizes error (here α≈0.5 minimizes EM near zero).
- **4.5 Limites de méthodes de lissage exponentiel**: advantage (cheap/inexpensive forecasts); disadvantages — (1) no guarantee of optimality on a given dataset, (2) can't produce prediction intervals (no probabilistic framework). Notes that probabilistic models can address these limitations, and that (except multiplicative HW) exponential smoothing methods correspond to particular probabilistic models.
