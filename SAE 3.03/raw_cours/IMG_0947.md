# IMG_0947 — Page 21: Double exponential smoothing (Holt/LED)

**Content:** **4.3 Le lissage exponentiel double de Holt (LED)**.

- Holt (1957) extends simple smoothing to fit a line instead of a constant.
- Model: x_t = b + at + e_t (locally linear trend, no seasonality).
- Forecast: x̂_T(h) = b̂_T + â_T·h, derived from two nested smoothing operations S₁(T) and S₂(T) (formulas given), with â_T = (1−β)/β·(S₁(T)−S₂(T)) and b̂_T = 2S₁(T)−S₂(T).
- Boxed **Proposition**: initialization â₂=x₂−x₁, b̂₂=x₂; update rules â_T = â_(T−1) + (1−β)²(x_T − x̂_(T−1)(1)), b̂_T = b̂_(T−1) + â_(T−1) + (1−β²)(x_T − x̂_(T−1)(1)).
- Remark: generalizable to higher-degree polynomial trends via iterated smoothing operators S_p(T).
