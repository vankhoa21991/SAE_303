# IMG_0940 — Page 14: Seasonal correction, additive & multiplicative

**Content:**

- **3.1 Correction des variations saisonnières pour le modèle additif** (x_t = m_t + s_t + e_t): step-by-step procedure —
  1. Approximate trend m̂_t (moving average or parametric fit).
  2. Estimate seasonal coefficients s_t from the (n−1) differences {x_t − m̂_t} per period, averaged/median after removing outliers, corrected to sum to zero (s*_t = ŝ_t − s̄).
  - Definition of **série désaisonnalisée (CVS)**: x*_t = x_t − s*_t.
  - Interest: CVS values become directly comparable across seasons (e.g., January vs. July).
  - **Calcul des erreurs**: residual e_t = x_t − m̂_t − s*_t = x*_t − m̂_t; expected to be small, mean-zero, ~N(0,σ²).
- **3.2 Correction des variations saisonnières pour le modèle multiplicatif** (x_t = m_t × s_t × e_t): same step structure begins (trend estimation), to be continued on the next page.
