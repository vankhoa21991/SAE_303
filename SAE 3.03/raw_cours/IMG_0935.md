# IMG_0935 — Page 9: Trend analysis — parametric & moving averages

**Content:** Start of **Section 2. ANALYSE DE LA TENDANCE**.

- Objective: extract a trend-only series m_t from the raw series x_t.
- **Tendance paramétrique**: fitting an analytic function via least squares. Forms listed: linéaire (m_t = a+bt), quadratique (m_t = a+bt+ct²), logarithmique (m_t = a+b·ln(t)), exponentielle (m_t = λe^(a+bt)), puissance (m_t = λtᵃ), plus logistique/Gompertz. Limitation: assumes a fixed functional form.
- **Tendance non-paramétrique**: uses a "filter" (boîte noire) X → Y to regularize the series without assuming a functional form. Introduces linear filters generally: y_t = Σ_k∈K α_k·x_(t+k) with Σα_k = 1. Two main linear filters mentioned: moving average and simple exponential smoothing.
- **2.1 Moyennes mobiles simples et centrées / 2.1.1 Calcul**: formal definition of the centered moving average of order p, given separately for **p odd** (p=2k+1) and **p even** (p=2k), with the summation/averaging formulas.
