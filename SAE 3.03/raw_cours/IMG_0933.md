# IMG_0933 — Page 7: Residual component, composition models, model-choice method

**Content:**

- **1.3.3 Composante résiduelle**: the residual/accidental component e_t is "noise" — irregular, usually low-intensity, random, mean zero (example causes: strikes, exceptional weather, financial crashes).
- **1.4 Modèles de composition**: three ways to combine the components, with formulas filled in by hand:
  - Modèle additif: x_t = m_t + s_t + e_t
  - Modèle multiplicatif: x_t = m_t × s_t × e_t
  - Modèle mixte: x_t = m_t × s_t + e_t (not covered in this course)
  - Note: a positive multiplicative series can be turned additive via log: ln(x_t) = ln(m_t) + ln(s_t) + ln(e_t).
- **1.5 Méthodes de choix du modèle** — **Méthode de la bande**: plot the line through the maxima and the line through the minima of the series.
  - If the two lines are roughly parallel → additive model.
  - If not parallel → multiplicative model.
  - Two example quarterly charts side by side illustrate constant-amplitude (additive) vs. growing-amplitude (multiplicative) variation, each annotated with "Droite passant par les maxima/minima," "Tendance," "Saison."
- Start of **Méthode du profil** (superimposed curves method): parallel curves → additive; curves with increasingly pronounced peaks/troughs → multiplicative.
