# IMG_0948 — Page 22: Holt-Winters smoothing

**Content:** **4.3(§) Le lissage exponentiel de Holt-Winters (HW)**.

- Figure 20: potato price prediction via additive seasonal exponential smoothing (observed vs. fitted, 2009–2018).
- Generalization of double smoothing, enabling: local linear trend; local linear trend + additive seasonality (covered in this course); local linear trend × multiplicative seasonality (not covered).
- **4.3.1 La méthode non saisonnière de HW**: preliminary steps (choose additive/multiplicative model, deseasonalize). Model x_t = b+at+e_t.
  - Initialization: b̂₁=x₁, â₁=x₁−x₀.
  - Update: b̂_T = α·x_t + (1−α)(b̂_(T−1)+â_(T−1)); â_T = γ(b̂_T − b̂_(T−1)) + (1−γ)â_(T−1).
  - Trade-off remark: more flexibility but two parameters to tune; α,γ near 1 → smooth/heavily-past-weighted forecast.
- **4.3.2 La méthode saisonnière additive de HW** (intro): model x_t = b+at+s_t+e_t, p = period of s_t.
