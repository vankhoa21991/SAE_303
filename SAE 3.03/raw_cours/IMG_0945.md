**Content:**

- Worked numeric forecast example continuing the aviation-fuel-sales case: for t=17 (1st trimester 2009), handwritten calculations show:
  - Trend regression: m_t: y = −0.032x + 5.59 → m̂₁₇ = 5.046.
  - Additive forecast: x̂₁₇ = m̂₁₇ + s*₁₇ = 5.046 − 1.61 = 3.436 (using s*₁₇ = s*₁ = −1.61).

- **4.2 Introduction au lissage exponentiel (~1960)**: purpose (forecast from recent observations without redoing full parameter estimation) and characteristics (generalizes moving average; weights recent values more).
- **Tableau 8**: summary table of smoothing methods — Lissage exponentiel simple (constant model, β), Lissage exponentiel double/Holt (linear trend, β), Holt-Winters non-saisonnier (linear trend, α & γ), Holt-Winters saisonnière additive (α, β, γ — trend+additive seasonality), Holt-Winters saisonnière multiplicative (α, β, γ — trend×seasonality, not covered), each mapped to the type of series it suits.
