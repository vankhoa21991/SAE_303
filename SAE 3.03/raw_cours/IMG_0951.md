# IMG_0951 — Page 25: Compléments (hors programme)

**Content:** **Section 5. COMPLÉMENTS (HORS PROGRAMME)** — extra topics mentioned but not required for the exam.

- **5.1 Autres indices descriptifs**: autocovariance/autocorrelation (ACF, PACF) as tools for identifying AR/MA order; definition of a (weakly) stationary time series (constant mean/variance/autocorrelation over time), with white noise as an example.
- **5.2 Autres méthodes de décomposition**: la méthode Census; décomposition via LOESS (locally estimated scatterplot smoothing).
- **5.3 Prévisions via les modèles autorégressifs ARMA**: overview of AR, MA, and ARMA models guided by ACF/PACF behavior; subsections list ARMA(p,q), seasonal ARMA (SARMA), ARIMA(p,d,q)/SARIMA, ARMAX, and model comparison via AIC (lower AIC = better model, balancing fit quality and simplicity).
- **5.4 Autres**: conditional heteroscedasticity; study of decomposition-related noise (covered in TP).
